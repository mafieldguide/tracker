# MA Field Guide: public tracker

This is where you can suggest questions, report corrections and submit evidence for [MA Field Guide](https://mafieldguide.com), an unofficial, community-maintained FAQ for Math Academy users.

> **Unofficial.** MA Field Guide is not affiliated with, endorsed by, or speaking for Math Academy. This repository holds issues only. There is no code here.

## How to contribute

Every contribution is a GitHub issue. Pick the one that fits:

| I want to… | Use | Needs |
| --- | --- | --- |
| Ask for a question to be added | [New question](https://github.com/mafieldguide/tracker/issues/new?template=new-question.yml) | The question, phrased as a user would ask it |
| Say an answer is wrong or outdated | [Correction](https://github.com/mafieldguide/tracker/issues/new?template=correction.yml) | The FAQ page and a **source link** |
| Share a source relevant to an answer | [Evidence](https://github.com/mafieldguide/tracker/issues/new?template=evidence.yml) | The FAQ page or question, and a **source link** |

You can also use the **Suggest a correction** link at the bottom of any FAQ page. It opens the correction form with the page already filled in.

### Tips for a good submission

- **Link to the original source** (official page, message link, episode link and so on). A screenshot is backup evidence, not a replacement for the link.
- **Check the site first.** Your question may already be answered, and every answer shows its sources and history.
- **Crop screenshots tightly** and remove unrelated messages. Redact ordinary usernames and avatars where identity isn't relevant.
- **One topic per issue.**

## What happens next

1. The maintainer reads your issue and checks the source independently. A link or screenshot is not treated as verified just because it was supplied.
2. If it's accepted, the maintainer writes the change to the FAQ. You don't need to write the answer yourself.
3. The issue is closed with a link to the published page. Issues that aren't used are labelled `declined` or `duplicate`.

Reviews are done by one person in their own time, so please be patient.

Please read the [submission policy](SUBMISSION_POLICY.md) before posting. It covers privacy, what gets declined, and takedown requests.

## This is not a support channel

For billing, login or account access, privacy or security incidents, account-specific bugs, or anything involving your account data, contact [Math Academy](https://www.mathacademy.com) directly. Nobody here can see your account.

## Labels

Workflow labels only: `new-question`, `correction`, `evidence`, `needs-review`, `accepted`, `declined`, `duplicate`. They don't mirror FAQ statuses or topics.
